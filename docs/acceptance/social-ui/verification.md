# Компактный профиль и события

Изменения касаются только представления. События, онлайн, награды и рекорды по-прежнему приходят из существующего API.

- Онлайн и последние пять событий объединены в одно сворачиваемое окно. Каждое событие оформлено как уведомление со значком. На широком экране окно закреплено справа внизу. На телефоне находится в потоке страницы и не перекрывает кнопку «Забрать».
- Для достижений нарисованы собственные SVG-значки: шар, кубок, компас, горы, молния, огонь и крылья. Закрытые достижения обесцвечены. Дополнительные библиотеки и сторонние изображения не используются.
- В профиле сразу видны три рекорда. Полная статистика, достижения и коллекция раскрываются отдельно. Убрано повторное пояснение о косметике; правила сохраняют информацию о её назначении.
- Анимация появления применяется только к полученным событиям и отключается при reduced motion. Новые игроки или события не генерируются.

Примеры текста:

| Было | Стало |
| --- | --- |
| Имя · забрал ×4,12 | Имя и «забрал ×4,12» на отдельных строках |
| Все рекорды · сыграно 3 | Все рекорды |
| Задание выполнено · +1 фрагмент | Задание выполнено: +1 фрагмент |
| Фрагменты → бонусы после полёта | Обмен фрагментов после полёта |
| ← Новее / Раньше → | Новее / Раньше |

Проверка интерфейса выполняется через nginx Docker. Основная база сохраняется; браузерные игровые тесты создают отдельную временную базу.

Проверены скриншоты основной Docker-сборки: окно событий на 320/1440 px, компактный профиль на 320 px и иллюстрированные достижения на 1440 px. Снимки находятся рядом с этим документом.

Frontend: 91 тест проходит. TypeScript и production build проходят. Backend: повторно выполнены 82 теста, ошибок нет. Серверный код и миграции не менялись.

Итоговый real-backend E2E: 15/15 сценариев прошли (Chromium, Firefox, WebKit). Проверены игра, профиль, экипировка, достижения, онлайн и события между двумя независимыми аккаунтами, а также ширины 320–1920 px. В первом прогоне обнаружено несовпадение регистра подписи «Ты»; исправлено до итогового полного прогона. Тестовые контейнеры и их отдельная база удалены автоматически. Основные PostgreSQL, backend и frontend работают и healthy.
